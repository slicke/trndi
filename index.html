What happens after you click

Trndi is made by one person, not a big company, so Windows has never heard of it and shows a blue warning the first time. That is normal. Here is what it looks like and what to click:

Windows protected your PC

Microsoft Defender SmartScreen prevented an unrecognized app from starting. Running this app might put your PC at risk.

1. More info

App: TrndiSetup.exe
Publisher: Unknown publisher

2. Run anyway Don't run
  1. Click the small More info link.
  2. Click Run anyway.
  3. Follow the installer. Trndi opens and asks how to connect to your CGM.

The portable version has no installer: it is a folder you keep wherever you like, on a USB stick if you want. Windows still shows its blue warning the first time you start it.

  1. Right-click the downloaded .zip and choose Extract All…. Pick a folder you will keep, for example Documents\Trndi. Do not run it from inside the zip window.
  2. Open that folder and double-click Trndi.exe.
  3. Windows says Windows protected your PC. Click the small More info link, then Run anyway. It only asks once.
  4. Trndi opens and asks how to connect to your CGM.

Nothing is added to the Start menu. Make a shortcut to Trndi.exe yourself if you want one. Settings are stored in the Windows registry, not in the folder.

Trndi is made by one person, not a company that pays Apple to sign apps, so your Mac will refuse to open it the first time. Two minutes fixes it:

  1. Open the downloaded .dmg and drag Trndi into Applications, like any other app.
  2. Open Terminal: press ⌘+Space, type Terminal, press Enter. A plain text window opens.
  3. Copy this line, paste it into that window, and press Enter: 
    xattr -c /Applications/Trndi.app
    Nothing visible happens. That is fine.
  4. Open Trndi from Applications. It asks how to connect to your CGM.

Why? The line removes the "downloaded from the internet" mark that makes macOS block unsigned apps. It changes nothing else. See the macOS notes.

  1. Double-click the downloaded .deb and your software installer takes it from there. Or, in a terminal:

  2. The package asks for Qt6Pas, so on Debian 13 and Ubuntu 25.04 and newer that library is installed alongside and you are done. On older releases it is not in the repositories, so the package installs without it and Trndi will not start — install it yourself first, as the table below shows.
  3. Start Trndi from your app menu. It asks how to connect to your CGM.
  1. Double-click the downloaded .rpm and your software installer takes it from there. Or, in a terminal:

  2. The package asks for Qt6Pas, so on Fedora 43 and newer that library is installed alongside and you are done. On older Fedora, or where the package is spelled differently, install it yourself first, as the table below shows.

An AppImage is a single file that runs without installing. Trndi's does not carry the Qt6Pas library inside it, so that one thing has to be installed first.

  1. Install Qt6Pas with your package manager — the table below gives the command for your distribution.
  2. Make the file executable: right-click it, Properties, tick Allow executing as program. Or in a terminal: 
    chmod +x Trndi-*.AppImage
  3. Double-click it. Trndi opens and asks how to connect to your CGM.

Nothing is added to your app menu. The GNOME and KDE panel indicators are inside the AppImage but need copying out by hand; the .deb and .rpm install them for you.

Getting Qt6Pas on your distribution

Trndi is drawn with Qt6 and needs one extra library, Qt6Pas. Distributions spell it differently, and the older ones do not carry it at all. Find yours:

DistributionInstall it with
Debian 13 (trixie) and newersudo apt install libqt6pas6
Debian 12 (bookworm)Not in the repositories — use the upstream .deb below
Ubuntu 25.04 and newersudo apt install libqt6pas6
Ubuntu 24.04 LTS and olderNot in the repositories — use the upstream .deb below
Raspberry Pi OS (trixie)sudo apt install libqt6pas6
Raspberry Pi OS (bookworm)Not in the repositories — use the upstream arm64 .deb below
Fedora 43 and newersudo dnf install qt6pas
RHEL, AlmaLinux, Rocky 10sudo dnf install qt6pas
Needs the EPEL repository enabled.
Arch, Manjaro, EndeavourOSsudo pacman -S qt6pas
openSUSEsudo zypper install libQt6Pas6
Not found? It lives in devel:languages:pascal on the openSUSE Build Service.
Gentoosudo emerge dev-libs/libqt6pas
Anything elseSearch your package manager for qt6pas, libqt6pas6 or libQt6Pas.so.6

Not in your repositories? The library's own project publishes ready-made packages — a .deb for amd64 and arm64, an .rpm for x86_64, and a plain tarball — at davidbannon/libqt6pas. Install the one for your machine the same way you installed Trndi. It needs Qt6 itself (6.2.4 or newer) and glibc 2.34 or newer, so it will not work on very old releases.

Setup

Connect it to your CGM

The first time Trndi starts it asks which system you use and what to log in with. This is what to have ready:

🌙 Nightscout

Your Nightscout address (the one you open in a browser) and its API secret or token. Trndi fetches your high/low limits from the site automatically.

📡 Dexcom Share

The same email and password you log in to the Dexcom app with — not a Follow account. Sharing must be switched on in the Dexcom app first. Pick the Dexcom entry for your region (US, EU or Japan). See the Dexcom setup guide.

💙 Tandem Source

The email and password for your Tandem Source account. Readings can arrive a few minutes late here; that is Tandem's side, not yours. See the Tandem setup guide.

🩸 Medtronic CareLink

Log in once in your browser with a Care Partner account using the bundled helper, then paste the token into Trndi. See the CareLink setup guide.

🩹 FreeStyle Libre

You need a second account before you start. Trndi logs in as a LibreLinkUp follower, not as the LibreLink app on the phone. Make a LibreLinkUp account with a different email, invite it from the LibreLink app (Connected Apps → LibreLinkUp), and accept the invitation in the LibreLinkUp app. Then give Trndi that email and password. See the Libre setup guide.

📶 xDrip+

Enable the local web server in xDrip+, then enter that IP address and password in Trndi.

Your first five minutes

  1. Download and open Trndi using the button above. Windows and macOS will warn you the first time; the steps under the button show what to click.
  2. Read and accept the notice. Trndi is not a medical device and its alerts are not an alarm system. It says so up front.
  3. A setup guide opens. Pick your CGM system from the list, type in the login from the box above, and press Test connection. Green tick means you are done.
  4. Choose mmol/L or mg/dL and check the high and low limits. They start at the usual 4–10 mmol/L (70–180 mg/dL); change them if your nurse gave you others.
  5. Press Finish. Your reading appears within a minute, in green, orange or red.

💡 There are no buttons on the window. Right-click the reading to get the menu with Settings, privacy mode, snooze and everything else. On a touch screen, press and hold.

Compatibility

Supported CGM Sources

Connect to the system you already use — no extra hardware needed.

🌙

Nightscout

Self-hosted or cloud. High/low settings auto-imported from your server. Supports both v2 and v3 APIs.

📡

Dexcom Share

US, EU, and Japan regions supported. Connects via the official Dexcom Share API — classic and new.

💙

Tandem Source

Connects to the Tandem Source cloud with your existing Tandem account credentials.

🩸

Medtronic CareLink

Follow a Medtronic pump via the CareLink Connect follower API — US and EU regions. One-time browser login; Trndi keeps the session alive. Experimental.

🩹

FreeStyle Libre

Follows an Abbott sensor through a LibreLinkUp follower account. Works in every region with no server to pick. High/low limits come from your LibreLinkUp alarm settings. Alpha.

📶

xDrip+ WiFi

Connects locally over your home network to the xDrip+ Android app — no cloud needed.

Features

What you get

🔢

One big number

Your reading, the arrow, and how many minutes old it is. The whole window turns green, orange or red, so you can tell from across the room.

📊

The last few hours

A row of dots shows where you have been. You pick how far back it goes, and which colours mean high, low and "fine but drifting".

⏱️

Never lies about old data

When no new reading has come in, the number dims and a note tells you how long it has been quiet, so a stale value never looks fresh.

🔔

Alerts you can snooze

Desktop notifications, a sound, and it can pause your music to get your attention. Snooze for 15, 30 or 60 minutes when you are already on it.

🙈

Privacy mode

Sharing your screen in a meeting? One click hides the number and keeps the colours, so you still know where you are.

🌙

Dims at night

Between the hours you choose, a calm reading fades to almost black so a bedside screen stops lighting the room. Highs and lows still shine through.

🔮

A look ahead

Optional, experimental predictions show where the trend is heading 5, 10 and 15 minutes out. A guide, not a promise.

♿

Reads aloud

Text-to-speech can announce readings. High contrast mode, adjustable voice and speed, and controls that work with screen readers.

📱

Works on a wall screen

Touch-friendly and happy on a Raspberry Pi with a small display, by the bed or in the kitchen.

👥

More than one person

Parents and partners can follow several people, each with their own CGM system and settings.

🌍

In your language

Ships in six languages, including Swedish, German and French.

💝

Free, forever

No subscription, no ads, no account, no data collection. Open source under the GPLv3.

For the tinkerers

You can ignore all of this. It is there if you want it.

  • JavaScript extensions — a built-in QuickJS engine runs your own scripts on every reading. Official ones exist for IFTTT and Discord.
  • Web API — a local endpoint with a live event stream, so other apps and dashboards can read your data without polling.
  • Desktop indicators — a GNOME Shell extension, a KDE Plasma widget and a Waybar module that show the current reading in your panel.
  • Razer Chroma — keyboard and mouse lighting follows your range on Windows and Linux.
  • Kiosk mode — start with --kiosk for a fullscreen, always-awake display.
  • Proxy support — a configured proxy is used exclusively, never bypassed.
  • Runs natively — no browser, no Electron, no cloud in between. One small binary per platform.

Prefer the command line? Meet trndi-cli

An optional extra for people who work in a terminal. It shows your readings as plain text, so they fit in a shell prompt, a script, or a Raspberry Pi with no desktop. It reuses the settings you already made in Trndi. If you are happy with the desktop app, you can skip it.

Following more than one person? Meet trndi-multi

An optional companion for parents, partners and caregivers. Every account becomes a tile in one window, coloured by range, with a sparkline of the last hours. Put it on a wall display or a spare screen. It shares your Trndi accounts, and can add new ones too.
